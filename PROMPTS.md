# AI Usage Documentation

## Project: Car Dealership Inventory System

### Purpose

AI tools were used as development assistants during the implementation of the Car Dealership Inventory System. Their suggestions helped with coding, debugging, styling, testing, and documentation.

## Areas Where AI Assistance Was Used

### 1. Backend Development
- Assistance with Express.js REST API routes.
- Help with user registration and login.
- Assistance with JWT authentication and role-based authorization.
- Help implementing vehicle inventory operations, including adding, updating, deleting, purchasing, and restocking vehicles.

### 2. Database
- Assistance with SQLite database tables and queries.
- Help validating vehicle prices and quantities.
- Assistance with inventory updates.

### 3. Frontend Development
- Help implementing React login and registration forms.
- Assistance with vehicle dashboard and inventory display.
- Help implementing search, purchase, and administrator controls.
- Assistance with CSS styling and responsive layout.

### 4. Testing and Debugging
- Help understanding and resolving development errors.
- Assistance with backend automated tests.
- Guidance on running Jest tests and interpreting test results.

### 5. Documentation
- Assistance preparing README.md and project setup instructions.
- Guidance on documenting AI usage and preparing the project for submission.
